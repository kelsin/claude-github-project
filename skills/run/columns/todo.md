2. `CGP move <item> plan`.
3. Read the story and explore the code through the worktree (`CGP worktree <item>`, then `CGP sync <item>`). Rate the story (rule 4).
4. Spawn planners (count by rating). Merge their drafts into one plan. Put every assumption in the Assumptions section.
5. Record the files and directories the plan changes: `CGP touches <item> <paths...>`. Publish the plan artifact (rule 9) and `CGP set <item> plan <url>`.
6. Post a status comment: plan link, risk rating, key assumptions.
7. `CGP move <item> plan_review`.
